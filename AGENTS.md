# SPIKE / СПАЙК

SPIKE — хардкорный экшен от третьего лица для Android на Unity. Основа игры — многофазная дуэль с боссом, в которой игрок использует катану, бластер и защитные приёмы.

## Где искать контекст

- [ТЗ и правила игры](docs/GAME_DESIGN.md) — цели, игровой цикл, фазы боя, глобальные жизни и экраны. Сверяйся с ним, когда задача меняет поведение игры.
- [Архитектура скриптов](docs/SCRIPT_ARCHITECTURE.md) — точки входа, связи систем и расхождения с ТЗ, найденные в текущем проекте. Начинай с нужного раздела перед изменением соответствующей системы.
- [Игровые скрипты](Assets/_GameFiles/Scripts) находятся в `Assets/_GameFiles/Scripts`. Для работы с `Assets/_GameFiles/ECS` требуется явное разрешение пользователя.

## Работа с Unity

- При изменении поведения проверяй классы и их подключения в используемой сцене и префабах. Список сцен сборки находится в [EditorBuildSettings.asset](ProjectSettings/EditorBuildSettings.asset). Версия редактора указана в [ProjectVersion.txt](ProjectSettings/ProjectVersion.txt), пакеты — в [manifest.json](Packages/manifest.json).
- Сохраняй связи Unity при переносе или переименовании ассетов. Учитывай `.meta`-файлы, сериализованные поля и ссылки из Inspector. При изменении формата сохранений учитывай уже записанные данные.
- Настраивай действия игрового ввода в [InputActionMapSystemDefault.inputactions](Assets/_GameFiles/InputActionMapSystems/InputActionMapSystemDefault.inputactions). `InputReader.cs` генерируется из этого ассета.
- Если меняешь связи между подсистемами, точки входа или формат сохранений, обнови соответствующий раздел архитектуры. Изменения игровых правил по задаче отражай в ТЗ.

## Прямое управление редактором

На компьютере доступна команда `unity` из официального Unity CLI. В проект установлен `com.unity.pipeline` версии `1.0.0-pre.1`. Для выполнения команд проект должен быть открыт в Unity, а компиляция завершена. Проверка соединения и чтение открытых сцен из корня проекта выполняются так.

```powershell
unity status --proxy-disable --json
unity command --project-path . scene list_open --proxy-disable --json
```

Список доступных операций можно получить через `unity command --project-path . --detail compact --proxy-disable --json`, а параметры нужной операции — через фильтр `--query` с `--detail full`. Флаг `--proxy-disable` позволяет обращаться к локальному редактору напрямую. При ошибке доступа к локальному соединению запроси разрешение на выполнение команды с доступом к редактору.
